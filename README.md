Rever UI Cloner is an innovative developer tool and web application designed to instantly clone any website's user interface and translate it into clean, responsive React + Tailwind CSS code. 

The project features a full-featured web dashboard and an official **Model Context Protocol (MCP) Server** that hooks directly into AI models (like Claude Desktop) to grant them local UI cloning superpowers.

---

## ⚡ Features

### 1. Web Platform (`/src`)
- **Interactive UI Dashboard**: Manage credits, browse recently discovered platforms, and initiate web interface cloning processes.
- **Site Time Machine**: Navigate historical UI versions of indexed websites and extract styles from specific dates.
- **Site Showcase**: Filter, search, and explore cloned websites generated by the developer community.
- **Supabase Integration**: Stores user profiles, logs, dynamic discovery data, and handles authorization/credits.

### 2. Rever MCP Server (`/rever-mcp`)
- **Direct AI Integration**: Exposes custom tools to local AI assistants to examine, dissect, and reconstruct elements from any URL on the fly.
- **Zero Scraping Required**: Bypasses typical DOM scraping restrictions by utilizing Rever's custom rendering pipeline to produce structured UI components.

## 🚀 Getting Started

### 1. Web Platform Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com/chaoui-ahmed/rever.git
   cd rever
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
4. **Run development mode**:
   ```bash
   npm run dev
   ```

### 2. MCP Server Installation
Follow the instructions in the [rever-mcp/README.md](file:///tmp/repos/rever/rever-mcp/README.md) to integrate the UI cloner with your local AI workspace (e.g., Claude Desktop).
