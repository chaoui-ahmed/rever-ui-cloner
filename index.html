Rever: turn any website into a prompt to rebuild its UI

Paste a URL. Rever takes a full-page screenshot and writes a detailed prompt describing the layout, sections, components, colors, typography and spacing. Paste it into Lovable, v0, Bolt, Claude or Cursor to recreate the design in React + Tailwind.

For people

No account needed: paste a URL and buy a pack of generations by card (from 9,99 € for 10). Browse ~10,000 sites built with Vercel and Lovable in the showcase.

For AI agents

  • API: POST https://www.aypiai.online/api/generate-prompt with {"url": "https://example.com"}
  • Payment: $0.001-$0.05 per call in USDC on Base with the x402 protocol. Any x402 client (e.g. @x402/fetch) pays automatically. Or use a pack key in X-Access-Key.
  • Also: /api/design-tokens ($0.05, palette, fonts, spacing and Tailwind theme as JSON), /api/screenshot ($0.02), /api/tech-stack ($0.02, framework, hosting and tools used by a site), /api/brand-kit ($0.03, logo, colors, fonts), /api/page-markdown ($0.01, page as Markdown), /api/meta ($0.005, title, description, preview image)
  • Docs: llms.txt, full guide, OpenAPI spec, MCP server card
  • MCP server: https://www.aypiai.online/mcp (Streamable HTTP, tool clone_ui), or locally with rever-mcp
