Rever: turn any website into a prompt to rebuild its UI

Paste a URL. Rever takes a full-page screenshot and writes a detailed prompt describing the layout, sections, components, colors, typography and spacing. Paste it into Lovable, v0, Bolt, Claude or Cursor to recreate the design in React + Tailwind.
